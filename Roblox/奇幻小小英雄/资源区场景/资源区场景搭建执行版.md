# 资源区场景搭建执行版

> 目标：在 Roblox Studio 里搭建第一版可玩的资源区场景。  
> 范围：只做独立传送进入的共享资源区，只包含木头和矿石，不做草药、蘑菇、怪物、战斗区。  
> 参考图：`资源区场景/ResourceZone_Concept_01.png`

---

## 1. 当前结论

混元 3D 生成结果适合作为**构图和美术参考**，但不要直接把 `Splats(.spz)` / `Splats(.ply)` 当成 Roblox 最终地图。

第一版最稳的做法是：

```text
参考混元画面
-> 在 Roblox Studio 手动搭 ResourceZone
-> 把树和矿石按现有 ResourceNodes 结构摆好
-> 接入当前已有采集系统
-> 测试传送、采集、返回主城
```

理由：

- Splats 更偏展示，不适合做可碰撞、可交互、可维护的 Roblox 地图。
- 资源区需要大量可采集节点，手动摆放更容易控制玩家站位和多人动线。
- 当前项目已经有资源采集系统，只需要场景和资源节点按规范放好。

---

## 2. 你需要学的最小 Studio 知识

先学这些就够：

1. `Part / Model / Folder`
   - 会创建 Folder。
   - 会把多个 Part 组合成 Model。
   - 会给 Model 改名字。

2. 移动、旋转、缩放
   - Move：移动物体。
   - Scale：调整大小。
   - Rotate：旋转朝向。

3. `Anchored` 和 `CanCollide`
   - 地面、树、矿石、装饰物大多需要 `Anchored = true`。
   - 玩家需要挡住的物体设置 `CanCollide = true`。
   - 纯装饰小物件可以按需要设置 `CanCollide = false`。

4. Attribute
   - 会给资源点加 Attribute。
   - 树：`ResourceType = "Tree"`。
   - 矿：`ResourceType = "Rock"`。

5. Explorer 层级
   - 必须按当前项目已有结构放资源点。
   - 不要随便新建不兼容的目录。

---

## 3. 最终 Explorer 结构

在 Roblox Studio 里整理成这个结构：

```text
Workspace
├─ Map
│  └─ ResourceZone
│     ├─ Ground
│     ├─ TeleportCamp
│     ├─ TreesArea
│     ├─ RocksArea
│     ├─ Decorations
│     └─ Boundaries
└─ Interactables
   ├─ ResourceNodes
   │  ├─ Trees
   │  │  ├─ Tree_01
   │  │  ├─ Tree_02
   │  │  └─ ...
   │  └─ Rocks
   │     ├─ Rock_01
   │     ├─ Rock_02
   │     └─ ...
   └─ Teleporters
      └─ ResourceToCity
```

说明：

- `Workspace.Map.ResourceZone` 放视觉场景。
- `Workspace.Interactables.ResourceNodes` 放真正能被采集系统识别的资源节点。
- `Workspace.Interactables.Teleporters.ResourceToCity` 保留为返回主城的传送点。

## 4. 场景布局

按参考图做三块区域：

```text
                 后方森林 / 小矿洞入口

        左侧伐木区       中心传送营地       右侧岩壁矿区
      TreesArea         TeleportCamp       RocksArea

                 前方玩家主要活动空地
```

### 中心传送营地

放在资源区中心，是玩家传送进来的第一眼焦点。

建议包含：

- 圆形石质传送阵 1 个。
- 蓝色发光传送门或魔法光柱 1 个。
- 返回主城传送点 `ResourceToCity` 1 个。
- 木牌 1-2 个。
- 灯笼 2-4 个。
- 木桶 / 箱子 4-8 个。
- 中心空地直径至少留出 35-50 studs。

### 左侧伐木区

用于木材采集。

第一版数量：

```text
可采集树：20-30 棵
树桩装饰：6-10 个
木材堆装饰：4-8 个
木栅栏：若干，用于边界和视觉引导
```

摆放要求：

- 树与树之间至少留 8-12 studs。
- 每棵可采集树前后左右都要有玩家站位。
- 不要把树全部堆在一起。
- 木材堆和树桩可以放在树木之间，但不要挡住采集点。

### 右侧矿石区

用于矿石 / 石头采集。

第一版数量：

```text
可采集矿石：8-12 个
岩壁 / 石山：1 组
矿车：1-2 个
木支架：2-4 个
木桶 / 箱子：4-8 个
蓝紫色水晶：少量装饰，先不要做成新资源类型
```

摆放要求：

- 矿石贴近岩壁，但矿石正前方要留玩家站位。
- 矿石节点之间至少留 8 studs。
- 发光水晶只做装饰，不要加 ResourceType，避免第一版系统范围变复杂。

### 外围边界

用这些限制玩家跑出资源区：

- 山体。
- 高岩壁。
- 密林。
- 木栅栏。
- 隐形墙。

隐形墙可以放在：

```text
Workspace.Map.ResourceZone.Boundaries
```

属性建议：

```text
Transparency = 1
CanCollide = true
Anchored = true
```

## 5. 资源节点设置

### 树节点

每棵可采集树放到：

```text
Workspace.Interactables.ResourceNodes.Trees
```

命名：

```text
Tree_01
Tree_02
Tree_03
...
```

每棵树都设置 Attribute：

```text
ResourceType = "Tree"
```

Model 要求：

- 最好是 Model，里面至少有一个可定位的主 Part。
- 模型整体 `Anchored = true`。
- 树干建议 `CanCollide = true`。
- 树叶可以 `CanCollide = false`。

### 矿石节点

每个可采集矿石放到：

```text
Workspace.Interactables.ResourceNodes.Rocks
```

命名：

```text
Rock_01
Rock_02
Rock_03
...
```

每个矿石都设置 Attribute：

```text
ResourceType = "Rock"
```

Model 要求：

- 矿石节点轮廓要明显。
- 玩家靠近后不能被卡住。
- 矿石前方留出采集站位。

## 6. 推荐搭建顺序

按这个顺序做，不要一口气铺满细节。

### Step 1：搭地面和大形

1. 在 `Workspace.Map.ResourceZone` 下创建 `Ground`。
2. 做一块开阔地面。
3. 用山体 / 岩壁 / 森林围住区域边界。
4. 保证中心空地明显。

### Step 2：搭中心传送营地

1. 创建 `TeleportCamp`。
2. 放圆形传送阵。
3. 放返回主城传送点 `ResourceToCity`。
4. 加灯笼、木牌、木桶、箱子。
5. 留出玩家传送落点空地。

### Step 3：搭左侧伐木区

1. 创建 `TreesArea`。
2. 先摆 8 棵树测试距离。
3. 确认玩家能绕树走。
4. 再扩展到 20-30 棵。
5. 添加树桩、木材堆、栅栏。

### Step 4：搭右侧矿石区

1. 创建 `RocksArea`。
2. 先搭岩壁。
3. 放 4 个矿石测试采集距离。
4. 再扩展到 8-12 个。
5. 添加矿车、木支架、碎石、水晶装饰。

### Step 5：整理可交互节点

1. 把可采集树移动到 `Workspace.Interactables.ResourceNodes.Trees`。
2. 把可采集矿石移动到 `Workspace.Interactables.ResourceNodes.Rocks`。
3. 逐个检查 Attribute。
4. 装饰树、装饰石头不要放进 `ResourceNodes`。

## 7. 测试流程

每完成一小步就测试，不要等全部搭完。

### 传送测试

1. 从主城靠近资源区传送点。
2. 按 E 传送到资源区。
3. 玩家落点应在中心营地空地。
4. 靠近 `ResourceToCity`。
5. 按 E 返回主城。

### 采集测试

1. 靠近 `Tree_01`。
2. 应显示采集提示。
3. 按 E 后显示采集进度条。
4. 完成后 HUD 的 Wood 增加。
5. 靠近 `Rock_01`。
6. 完成后 HUD 的 Stone 增加。

### 场景测试

1. 玩家从中心跑到左侧伐木区不卡住。
2. 玩家从中心跑到右侧矿区不卡住。
3. 树和矿石不会挡住主要道路。
4. 玩家不能轻易跑出资源区边界。
5. 资源点之间留有多人站位空间。

## 8. 第一版验收清单

完成后逐项检查：

- [ ] 中心有明显传送到达营地。
- [ ] `ResourceToCity` 返回主城传送点清楚可见。
- [ ] 左侧是明确的伐木区。
- [ ] 右侧是明确的矿石区。
- [ ] 可采集树数量达到 20-30 棵。
- [ ] 可采集矿石数量达到 8-12 个。
- [ ] 所有树都在 `Workspace.Interactables.ResourceNodes.Trees`。
- [ ] 所有矿石都在 `Workspace.Interactables.ResourceNodes.Rocks`。
- [ ] 树的 Attribute 是 `ResourceType = "Tree"`。
- [ ] 矿石的 Attribute 是 `ResourceType = "Rock"`。
- [ ] 玩家可以从主城传送进资源区。
- [ ] 玩家可以从资源区返回主城。
- [ ] 采树增加 Wood。
- [ ] 采矿增加 Stone。
- [ ] 没有加入草药、蘑菇、怪物、战斗区。

---

## 9. 暂时不要做的事

第一版先不要做：

- 砍树动作。
- 木材掉落物。
- 自动拾取。
- 多人贡献分配。
- 稀有矿。
- 怪物。
- 草药。
- 水晶作为独立资源。
- 复杂矿洞副本。
- Blender 深度优化。

这些都可以后续做。当前目标只有一个：**资源区能传送、能采树、能采矿、能返回主城。**
