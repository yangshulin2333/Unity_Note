**说明与设计理念**：

1. 关闭按钮统一放在 Header，下发给 UIManager 管理，保持全局一致。
    
2. EquippedPanel 显示当前已装备武器/护甲，ItemScroll 显示玩家背包列表。
    
3. SelectedFrame 控制选中高亮，避免修改图片。
    
4. 右侧 DetailPanel 显示选中物品属性及操作按钮。
    
5. 所有文字用 TextLabel，便于多语言切换。
    
6. InventoryItemTemplate 模板只存在 ItemScroll 下，动态生成格子。

## 三、数据结构

```lua
-- PlayerData（服务端存储）
PlayerData = {
    Gold = 100,
    Wood = 20,
    Stone = 15,
    Inventory = {
        ["WoodSword"] = {
            InstanceId = "123456_WoodSword_1710000000_1",
            ItemId = "WoodSword",
            Name = "木剑",
            Type = "Weapon",
            Level = 0
        },
        ["IronArmor"] = {
            InstanceId = "123457_IronArmor_1710000000_1",
            ItemId = "IronArmor",
            Name = "铁甲",
            Type = "Armor",
            Level = 0
        }
    },
    Equipped = {
        Weapon = "WoodSword",
        Armor = "IronArmor"
    }
}
```

- Inventory 为 key-value 格式，方便快速查找
    
- Equipped 明确写出 Weapon / Armor，未来扩展其他槽位（Accessory / Helmet / Shoes）
    
- Level 暂时只显示基础信息，不影响战斗（P7 后处理）

## 四、模块化流程

### 1. InventoryController（客户端）

职责：

- 打开/关闭背包 UI
    
- 显示背包物品
    
- 更新选中状态和右侧详情面板
    
- 监听 PlayerDataUpdate RemoteEvent
    

操作步骤：

1. 获取 PlayerGui 下 InventoryGui
    
2. 清理 ItemScroll 下除模板以外的元素
    
3. 遍历 `PlayerData.Inventory`：
    
    - Clone InventoryItemTemplate
        
    - 填充 Icon / NameLabel / LevelLabel / SlotLabel
        
    - 绑定鼠标点击事件 → 选中并显示 DetailPanel
        
4. EquippedPanel 显示当前装备
    
5. EquipButton / UnequipButton 点击调用 `InventorySystem` 服务端函数
    
6. 监听 PlayerDataUpdate：
    
    - 当 Inventory 或 Equipped 更新时刷新 ItemScroll 与 EquippedPanel
        

---

### 2. InventorySystem（服务端）

职责：

- 校验玩家穿戴请求
    
- 更新 PlayerData.Equipped
    
- 通知客户端刷新 HUD 与 InventoryGui
    

操作步骤：

1. 接收 EquipItemRequest / UnequipItemRequest
    
2. 检查 ItemId 是否在玩家 Inventory
    
3. 更新 Equipped 表
    
4. FireClient PlayerDataUpdate → InventoryController & HUDController 更新
    

---

### 3. 与 ShopSystem 的联动

- 商店购买装备 → 调用 DataService.AddInventoryItem(player, itemId)
    
- 服务器写入 Inventory
    
- FireClient PlayerDataUpdate → InventoryController 更新格子显示
    

---

### 4. 注意事项

- InventoryItemTemplate 仅做模板，生成物品格子使用 Clone
    
- SelectedFrame 控制选中高亮
    
- 所有文字用 TextLabel 以支持多语言
    
- DetailPanel 显示选中物品信息，可扩展额外属性
    
- 背包容量限制、装备出售、强化、拖拽等功能暂不做，后续 P7/P9/P10 再接入
